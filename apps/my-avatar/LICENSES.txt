3D models and textures (models/)
--------------------------------
Every file in models/ is built by tools/build-avatar-models.py from MakeHuman
assets, using the MakeHuman asset packs from https://static.makehumancommunity.org/assets/assetpacks.html. Every pack
used is a CC0 pack. MakeHuman's core assets are shared under CC0
(https://static.makehumancommunity.org/about/license.html).

Audit 2026-11-23: each source asset was found in the packs in Chris's Downloads folder, and its own file header was
read. Columns: app file | MakeHuman asset | pack | author (from the file) | license in the file header.
"Repo" marks the license read from the pack's page on makehumancommunity.org.

Duckling Tablet for Windows

A signed installer for Windows 10 and 11. Duckling on Windows uses the same subscription and parent portal as the Android and iPad apps.

Looking up the current version.

Which one

x64 is for most Windows PCs (Intel and AMD processors). ARM64 is for Windows on ARM devices, such as the Surface Pro X, Surface Pro 11 and Surface Laptop 7 with Snapdragon processors. In Settings, System, About, the line System type says which one a PC has.

Setting it up

  1. Run the installer from an administrator account. It installs the Duckling app and the Duckling service.
  2. Open Duckling from the Start menu. Type a parent's email, then the six-digit code Duckling sends to it, and the child's first name. A new family starts with a 7-day free trial, with no card. Choose a four-digit parent PIN. A family with a pairing code from the parent portal can choose I have a code from the website instead.
  3. In the parent area, under Lockdown: choose or make the child's Windows account, lock that account to Duckling, and restart into it.

After the restart the device signs in to the child's account by itself and shows Duckling full screen, with no taskbar. Other programs and websites open only when you allow them in the parent portal. Your own account is unchanged; to use it, press Ctrl+Alt+Delete, choose Sign out, and hold the Shift key while the sign-in screen appears.

The lockdown uses Windows' kiosk mode, which needs Windows 11 Pro, Education or Enterprise. On Windows 10 and on Windows 11 Home the apps work and the device is not locked down.

What the installer changes

The Duckling service runs as a Windows service so that the parent PIN, the settings and the lockdown stay out of the child's reach. It installs the learning apps, applies the parent portal's settings, installs newer signed versions of Duckling, and opens Duckling when the child signs in. The child's account, automatic sign-in and the kiosk are set up only when a parent chooses them in the parent area.

Removing it

In the parent area, Remove Duckling from this device turns off the lockdown and the automatic sign-in and uninstalls Duckling. Uninstalling Duckling Tablet in Settings, Apps does the same. The child's Windows account is kept.

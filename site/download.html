Duckling Tablet for Windows

The Windows installer is not published yet. This page will carry the signed installer, its version and its checksum when it is.

What the installer does

It creates a child account with automatic sign-in, sets up a kiosk that opens only Duckling, limits the browser to the websites you allow, and installs a small service that keeps the device in step with the parent portal. Removing Duckling from the portal or from the parent area on the device undoes all of it.

Windows 10 or 11. Windows Pro and Education use the built-in kiosk mode; Windows Home uses a guided setup with the same result for the child.
